# Modification notice

Public kit release **0.1.0**, prepared on **18 November 2026**.

Relative to upstream Firecrawl v2.11.162, this distribution includes:

- Native ARM64 build adjustments, PostgreSQL queue defaults, persistent services, bounded resource/concurrency settings and loopback-only deployment configuration.
- Scraper/browser private-destination guards and isolated deterministic fixture support, disabled in production.
- Native-text PDF page-limit enforcement, code preservation and financial table grounding with explicit exact unit transformations or typed unsupported results.
- Additional local mapping/search, expected-content checks and per-page batch error handling.
- A local MCP wrapper around the pinned official server, companion tools, manual monitors and a separate truthful read-only page reader.
- An optional OAuth/PKCE remote MCP gateway with bounded queues and sanitized timing records, without a shared public deployment.
- Operations, configuration, backup, scheduler-template and regression-test tools.

For public distribution, personal paths and domain bindings were replaced with generated local configuration and an explicitly configured remote base URL. Private runtime state, account packages, reports, copied handoff archives and private Git history were excluded. The full modified API/browser source is included; this is not a binary-only overlay.

See the Git history after this initial snapshot for subsequent changes. The upstream project and its authors retain their existing notices and licenses. No hosted-service parity or general financial accuracy guarantee is implied.
